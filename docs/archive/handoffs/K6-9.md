## The demo

The page owns the device, the encoder and every non-volume pass. Per frame, in one encoder:

1. `pool.update`, the level-set pool's `update`, `source.update` (one sparse source for the cloud and the explosion).
2. When the sun or a mesh moved: the sun's depth map (meshes + the level set through a second `vdbCreateLevelSetPassGpu`
   instance with the sun's orthographic camera; same formats, so one pipeline).
3. `frame.update(encoder, { camera, viewport, lights: [sun with a 'fit' shadow request], environment: the sky,
   occluders: [the sun map], emissionLight })`.
4. Opaque: the sky (the same equirect the core reduces, plus the sun disc), the ground / obelisk / plinth (one vertex
   buffer, Lambert: sun × mesh PCF × `vdbVolumeShadow`, sky hemisphere, `vdbEmissionIrradiance`), then the core's
   level-set pass (G-buffer output, depth-tested against the meshes) and a resolve pass that shades its G-buffer with the
   same `shade()`.
5. The volumes: `frame.render()` (after the scene-colour copy) or, with "composite: our shader", the present pass calls
   `vdbFrameIntegrate` + `vdbFrameComposite` itself.
6. Present: ACESFilmic + sRGB into the canvas (direct) or an rgba8unorm texture read back to a 2D canvas (readback).

Assets: the WDAS cloud (`fixtures/wdas/wdas_cloud_quarter_fp8.nvdb`, hosted) or the committed CC0 JangaFX
`cloud_04_variant_0000.wvdb`; the committed CC0 EmberGen `ground_explosion_0010.wvdb` (density + "flames" as two sparse
grids, both bundled with Vite's `?url`); the OpenVDB icosahedron level set (hosted) or a procedural ring-and-orb SDF
(`vdbBuildFromDense`, LevelSet class, ±3-voxel band). The sky is procedural (no sun disc in the map: the sun is its own
light, so the environment extraction finds the sky, not a second sun).

Controls (the gallery strip): lighting ('frame' / 'volume'), composite (core pass / our shader), quality, sun elevation
and azimuth, obelisk x, flames (emissive intensity), fire light (the probes' intensity on surfaces), sky, exposure,
vol → mesh, mesh → vol. Query: `?quality=`, `?lighting=`, `?composite=`, `?cloud=wdas|cc0`,
`?levelset=icosahedron|procedural`, `?test=1` (still, no loop, the statistical checks).

## Design notes

1. **No core change.** Everything the demo needs is in K6.1–K6.7. The level set casts into the sun's map through a
   second level-set pass instance (the cache shares the pipeline; one `record()` per instance per encoder).
2. **Receivers bind placeholders** until the core has a map / probes (a zeroed `VdbVolumeShadowView` reads 1, a zeroed
   `VdbEmissionGrid` 0), and rebuild their bind group when any input object changes (identity compare).
3. **The occluder input is one object per drawn map**: the transmittance signature compares the view object and the
   revision, so a new `createView()` each frame would redraw it every frame (with jitter on it redraws anyway, his rule).
4. **The host composite skips T ≥ 1 pixels** as the core's pass does (`vdbFrameCompositeColor` divides by α).
5. **The explosion is hotter than his.** His frame 10 at his values (0–3000 K, intensity 15, extinction 100, #555555)
   is black smoke with embers (his own capture shows it so); the demo uses 0–4500 K, 150, 25 and a lighter smoke so the
   one committed frame reads as fire across the scene (DIVERGES row below; the flames slider goes back to 15).

## DIVERGES rows (provisional, from V130; his renderer is mjurczyk 75e7345)

## Follow-ups

- K6.8: export the APIs demo 17 imports by path (`vdbCreateFrameRenderer`, `vdbSparseSourceGpu`, `vdbVolumeShadowWgsl`,
  `vdbEmissionProbeWgsl`, `vdbFrameIntegrateWgsl` / `Entries`, `vdbCreateLevelSetPassGpu`, the frame types) and switch
  the demo and the docs page to `@pmndrs/vdb`; drop the page's internal-API warning.
- A depth-only variant of the level-set pass (K6.6 follow-up): the sun map currently needs an rgba16float colour
  attachment beside it (8 MiB at 1024², 32 MiB at 2048²).
- Demo 17's mesh PCF (3 × 3, its own) and the core's occluder PCF (2 × 2 bilinear) differ at shadow edges by design; a
  shared receiver PCF in the core would make mesh and volume shadow edges match.
- The raw `?scene=` mode could also run `step3-environment-sky-midday-env-isolated` with an UltraHDR decode that does not
  need three (or a pre-decoded float copy of his map as a fixture).
- Timing of demo 17 on hardware (K6.T, quiet machine).
