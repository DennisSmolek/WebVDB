# K6.R1 handoff: reference follow-ups (light mapping, Mie, SH, blackbody, majorants) and the wider report

Builds on [K6-R.md](./K6-R.md) (the reference renderer: `core/reference/**`, `tools/reference/**`,
`scripts/k6/reference-report.mjs`). Design: [K6-core-renderer.md](../../dev/design/K6-core-renderer.md) §7.4, §3.6.
Owner context: the reference, not mjurczyk's renderer, judges quality. Report only: no timings (the seconds in the
report say how long a reference ran, nothing else).

## What landed

| Piece | Where | Notes |
|---|---|---|
| Light mapping per lighting mode | `tools/reference/scene.ts` `vdbReferenceLightsFromFrame(lights, { lighting })`, `vdbRefDistanceAttenuation` | 'frame': point and spot lights get three's `getDistanceAttenuation` (1/max(d^decay, 0.01), Frostbite window with `distance`), as `core/frame/wgsl/lighting.ts` and the TSL lighting pass; 'volume' (default): none (V84 holds for 'volume' only). Light records carry a falloff mode (0 none, 1 inverse square, 2 three's) + cutoff + decay. Frame lights take `distance` / `decay` and `{ kind: 'probe', sh }`. |
| Tabulated phase (Lorenz-Mie, Mie RGB) | `tools/reference/tables.ts` (`vdbReferenceMiePhaseTable('mono' \| 'rgb')`, `vdbReferencePhaseTable`, `vdbRefPhaseTableEval`, `vdbRefPhaseTableSample`); `VDBReferencePhase.table` | Evaluates his committed tables exactly as `vdbFrameMieTexel` (phase / isotropic at θ = π u², linear in u). Sampling: inverse CDF of the channel mean's marginal in u (piecewise constant over the 2047 intervals, binary search), weight per channel = phase / sampling density, so each channel is unbiased (his forward peak is 2746× isotropic: an HG proposal would not do). |
| Light probe (SH) | `VDBReferenceEnvironment.sh` (27 numbers, three's `SphericalHarmonics3` order and basis) | Radiance L(d) = Σ cᵢ Yᵢ(d), not clamped (the renderer's `vdbFrameShIrradiance` is its cosine convolution), gathered on escape like the other environment terms. |
| Blackbody emission colour | `vdbReferenceBlackbodyTable(exponent, cmf?)`, `VDBReferenceEmission.colorTable` | The renderer's LUT (256 log-spaced columns at the soot exponent, `vdbFrameBlackbodyColor`), read with the same log-temperature blend: equals `vdbFrameBlackbodyColor` to 2e-6. |
| Per-cell majorants | `VDBReferenceVolume.majorantGrid`; `vdbReferenceMajorantGridDense(volume, cellTexels)`, `vdbReferenceMajorantGridSparse(image, indexBox, { cellVoxels, clamp01, from })`, `vdbRefMajorantCell` | Piecewise-constant σ̄ per cell (x fastest over the unit box); tracking splits each volume interval at its cell faces (a 0 cell is skipped without draws). Dense: the texels a trilinear read in the cell can touch (exact bound). Sparse: each leaf's node-stats max and each active tile's value over the cells its voxels reach (index box dilated by one voxel); `from: 'voxels'` decodes every leaf voxel (checks the stats bound). Background assumed 0 (the harness warns otherwise). |
| GPU kernel | `core/reference/{wgsl,renderer}.ts` | Uniform 2,736 → 3,136 B (`sh` 9 × vec4 after the env rotation; volume record 160 → 192 B: `grid` (atlas z offset), `tables` (phase row + size, colour row + size)). Group 1 gains binding 5 (table texture, rgba32float: phase rows RGB + CDF, colour rows RGB) and 6 (majorant atlas, r32float 3D, grids stacked along z). `vdbReferenceTableLayout(scene)` dedupes tables and grids by identity. Still one `vdbRefTrack` call site and one call site per source channel. |
| Analytic + twin tests | `packages/vdb/test/tools/reference-r1.test.ts` (16), `packages/vdb/test/core/reference.test.ts` (+1) | See "Gates". |
| Harness: features twin | `examples/src/harness/k6-reference.ts` `?case=twin&source=features[&variant=phase]` | Sparse grids with per-cell majorants from node stats, Mie RGB + a 3-lobe synthetic table, blackbody table, a point light with three's falloff ('frame' mapping), a spot without (the 'volume' mapping), an SH probe. Per-channel image z added to `checkTwin` (a per-channel bias cancels in the sum over channels). |
| Report scene set | `examples/src/harness/k6-scenes.ts` (shared), `k6-scene.{html,ts}` (renderer: `./three` TSL or `backend: 'core'`), `k6-reference.ts ?case=scene` | WDAS cloud quarter Fp8 (sparse), openvdb.org smoke (sparse), absorbing bunny (albedo 0.5), thin bunny (extinction 5), each with his sun and with / without ambient 0.4; a point-light bunny (E = 1 at the centre in both mappings: three intensity E·d² with decay 2 for 'frame', E for 'volume'). |
| Reference page | `k6-reference.ts` `report` / `scene` | Convergence stop (`?target=` mean relative standard error of Y over the volume pixels, checked every `?check=` batches; `?budget=` is a safety cap), per-cell majorants by default, `?lighting=`, `?mie=mono\|rgb`, the overlap mask of multi-volume scenes (CPU: τ > 0.1 of two volumes along the pixel's centre ray). |
| Report | `scripts/k6/reference-report.mjs`, `scripts/k6/metrics.mjs` (+ `packages/vdb/test/scripts/k6-metrics.test.mjs`, 5) | Groups: his `volume`, `frame`, `two` (+ core rows), `mix` (V79), `silhouette` (V80), `mie`, `mie-rgb`, and the nine scenes (every lighting × TSL/core × MS mode the paths have; a `'multi-scale'` slot row). Metrics: luminance bias and median relative error over the volume pixels (Y from his sRGB blend inverted at the reference's coverage), SSIM (whole frame and the volume rectangle), PSNR, silhouette-band error Σ\|A − R\| / Σ\|R − bg\|, overlap-region bias. |

Exports: `tools/internal.ts`, `core/internal.ts` only (no public export, api-surface snapshots unchanged). No change
under `core/frame/**`, `three/**`, the WGSL generator, snapshots or budgets.
