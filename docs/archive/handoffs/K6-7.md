## Group 2 as built (for K6.1)

`slot = { group, firstBinding: b }`:

| Binding | What | Layout entry |
|---|---|---|
| b | the pool (the VDB module's `vdbPool`) | `vdbModuleEntries` (read-only storage; D10's one storage buffer) |
| b + 1 | `vdbSrcVolumes` | uniform, `minBindingSize = maxVolumes × 224` |
| b + 2 | `vdbSrcPyramid` (packed r16float atlas, `texture_3d<f32>`) | only `lod: 'coarse-pyramid'` |
| b + 3 | `vdbSrcSampler` (linear, clamp to edge) | only `lod: 'coarse-pyramid'` |

`source.wgsl()` does **not** include the VDB module (design §5.1: one module per shader, the renderer composes it).
`source.module` = `{ profile, helpers, types }` the module needs (profile `'march'` with `skipEmpty` or node-average;
helpers `cellBoundTrilinear` + `hddaCellEnd` with `skipEmpty`, `nodeAverage`, `fastTrilinear`). A shader that samples
only this source can use `source.moduleWgsl(slot, extraHelpers?)`.

WGSL (every function takes `v`, uvw in the source box [0, 1]³, already offset and wrapped by the caller):

```wgsl
fn vdbSrcDensity (v: u32, uvw: vec3f, lod: f32) -> f32;   // raw grid value (clamp01: [0, 1]); lod clamped to the volume's range
fn vdbSrcMask    (v: u32, uvw: vec3f, lod: f32) -> f32;   // level 0; 1.0 without a mask
fn vdbSrcAlbedo  (v: u32, uvw: vec3f, lod: f32) -> vec3f; // level 0, clamped [0, 1]; vec3(1) without
fn vdbSrcEmission(v: u32, uvw: vec3f, lod: f32) -> f32;   // level 0 raw value; 0.0 without
fn vdbSrcTexels  (v: u32) -> vec3f;                       // the density index box size
fn vdbSrcLodLevels(v: u32) -> f32;                        // 0 / 7 / pyramid L0 + atlas levels
// profile 'march':
fn vdbSrcSkipEmpty(v: u32, o: vec3f, d: vec3f, t0: f32, t1: f32) -> f32;                    // frozen form: = SkipSpan(.., 0, 0).x
fn vdbSrcSkipSpan (v: u32, o: vec3f, d: vec3f, t0: f32, t1: f32, lod: f32, cutoff: f32) -> vec2f; // NEW (below)
fn vdbSrcMaxIn    (v: u32, uvwMin: vec3f, uvwMax: vec3f) -> f32;                         // the volume's stats max
```

Host order per frame: `pool.update(enc)` → `source.update(enc)` (pyramids, followed layouts, the table via
`queue.writeBuffer`, stats readbacks) → build bind group 2 when `source.version` moved (it is `pool.version` + the
source's own atlas changes; `update()` also returns `rebind`). One `update()` per submitted encoder (the stats
readback maps the staging buffer one update after the copy was recorded).

The renderer fills nothing of the source's: boxes, ids, LOD ranges, pyramid placements and the stats max are in the
source's table. It keeps doing what the TSL `createNodes` did around the source: the mask is sampled at
`local + 0.5` (no offset/wrap), `densityCutoff`, `densityScale`, `extinction / worldScale`, `baseColor ×` albedo, the
emission temperature mapping, `getLod` from `slot.texels`, `normalizeDensity` from `slot.stats.meanNonZero`, and no
skipping when `wrap3D` or `offset3D` is set. Per-volume values live on the **slot** (`texels`, `lodLevels`, `stats`,
`boxToSource` (local unit box → index space, as the TSL source), `bbox`, `version` = content version); the source's
own `VDBVolumeSourceInfo` fields are aggregates.

## Contract deviations (K6.1 must know)

1. **`vdbSrcSkipSpan` added** to the march profile. The frozen `vdbSrcSkipEmpty(v, o, d, t0, t1) -> f32` has no `lod`
   (exactness depends on it: the dilated bound for coarse taps, off past it) and no cutoff, and returns only `ts`
   (the TSL march also uses `te`, the cell end, to ask again only after a zero sample past it). `vdbSrcSkipEmpty` is
   kept, exact for level-0 samples (cutoff 0). The dense source has no `vdbSrcSkipSpan`; a renderer emits the HDDA
   march only for sparse sources (`hdda` is a pipeline key, §5.2), or K6.2 adds the one-line dense version
   (`return vec2f(t0, 1e30);`).
2. **`wgsl()` excludes the VDB module**; `source.module` / `source.moduleWgsl()` are new (design §4.3/§5.1 imply it).
3. **`source.update(encoder)`** is new (the dense source needs none): the renderer calls it if present, after
   `pool.update`.
4. `VDBVolumeSlot` extends `VDBVolumeSourceInfo` (the design names only `source` + `v`; per-volume info is needed for
   a multi-volume source). For the dense source to be its own slot, `DenseSource` needs `source = this` and `v = 0`
   (K6.1's change; not made here to keep `dense.ts` conflict-free).
5. If K6.1 also declares `VDBVolumeSlot` (its brief says `core/frame/types.ts`), keep one declaration and re-export.

## Lifted, maths unchanged

Sample position, level-0 sampler (`vdbSampleFast` / cached accessor), node-average tap and LOD blend, coarse-pyramid
blend (level 0 → L₀ → his `sampleMipmapped`), clamp01, HDDA query and its enable/dilate rules (lod ≤ 3; node
averages: dilated for lod in (0, 3]; pyramid: dilated only for L₀ ≤ 2 and lod ≤ 2; mask → cutoff 0). Changes that do
not move values: the pyramid base is sampled through `clamp(uvw·size, ½, size − ½) + origin` in the packed atlas
instead of the hardware clamp-to-edge of its own texture; the node-average and coarse densities have one level-0 call
site (SwiftShader compile time), and the node LOD reuses the cached sampler. No bug found in the TSL maths.

## Gates and numbers (SwiftShader, headless Chromium, this machine; correctness only, no timings)

`e2e/k6-sparse.spec.ts` (committed + synthetic grids: no fixtures, no skips). Per source 4 live volumes (the CC0
cloud with its texture box, a synthetic blob with mask + RGB albedo + emission on their own boxes, its Fp8 quantization
with grey albedo, the blob under a second box; one removed and re-added), N = 1024 fixed-seed samples:

| Source | density max \|d\| | aux max \|d\| | exact fields | HDDA spans (mismatch / skipping / enabled) | exactness checks (violations) |
|---|---|---|---|---|---|
| `'none'` + clamp01 | 6.7e-8 | 5.8e-8 | 0 / 1024 | 0 / 184 / 1024 | 1112 (0) |
| `'coarse-pyramid'` (pyramidMax 16) | 1.2e-6 | 6.9e-8 | 0 / 1024 | 0 / 36 / 483 | 208 (0) |
| `'node-average'` | 5.0e-8 | 6.9e-8 | 0 / 1024 | 0 / 72 / 637 | 432 (0) |
| swap (followImage, after) | 3.6e-8 | 0 | 0 / 1024 | 0 / 65 / 225 | 408 (0) |

Bounds (per sample): `1e-4·(1 + scale)` (level 0: the pool's f32 trilinear vs the f64 twin, f32 sample positions),
plus `2⁻⁷·scale` when a pyramid tap contributes (the GPU pyramid is ≤ 1 f16 ulp from the CPU one (K3.2a), and hardware
filters with ~8-bit weights over 3 lerps); `scale` = the largest |tap|. On SwiftShader the worst sample uses 0.04 % of
its bound. HDDA spans: equal within `1e-5·(1 + |t|)` (all were exact). Exactness: for every span the GPU returned,
8 samples before `ts` (inside the box) read `density × mask ≤ cutoff` on the CPU twin.

G16a: a `followImage` source over a 32×32×11 FpN preview of the cloud, then `pool.replace` with the 73×110×34 FLOAT
cloud: **0** `createShaderModule` / `create*Pipeline*` calls across the swap, 1 relayout, the volume's `version` moved,
and the probe on the new image passes. Unit-test twin (fake device): the same swap creates 0; with `followImage: false`
the new type's pyramid kernels compile at the swap (> 0: the counter's fail-before).

Fail-before (GPU-side WGSL patches, each must fail the probe): `samplePos` (no half-voxel shift), `slot` (every volume
reads slot 0), `origin` (pyramid base ignores its packed origin), `blend` (wrong level-0 → pyramid blend), `dilate`
(coarse HDDA with the level-0 bound). Results: see "Spec runs" below.

## Follow-ups

- K6.1/K6.2: dense `vdbSrcSkipSpan` (one line) if the HDDA march is not keyed on the source kind; `DenseSource.source`/`.v`.
- K6.8: rewire `three/sparse-source.ts` onto this source (the TSL `imageStats` and `worldBox` are now duplicated by
  `vdbSparseDensityStats` and the core's `worldBox`); public exports with the one api-surface diff.
- `vdbSrcMaxIn` is the volume's global max; a box-aware bound (node stats over the uvw box) would let majorant-style
  callers do better (P1).
- The atlas only grows; a long session that removes large volumes keeps the high-water size (repack-and-shrink is a
  small change in `#pack` if memory matters).
- K6.T: the cost rule (skip only when lod ≤ 3) and `fastTrilinear`/`cacheAccessor` defaults in compute (§5.4 item 6).
