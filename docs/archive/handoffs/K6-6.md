# K6.6 handoff: level-set surfaces and point sprites in the core

Design: [K6-core-renderer.md](../../dev/design/K6-core-renderer.md) §3.9 (also §2.1, §5.3, §7), D34. Builds on K3.7
([K3-7.md](./K3-7.md)): the trace (`vdbLevelSetHit`, `vdbLevelSetNormal`) was core WGSL already. Reuses the K6.1
skeleton ([K6-1.md](./K6-1.md)): the per-device pipeline cache (`core/frame/pipelines.ts`), the uniform-struct
generator and packer (`core/frame/uniforms.ts`), the retire queue (`core/frame/resources.ts`).

## Design notes

1. **The surface is separate text, not a generator helper.** `vdbLevelSetSurfaceWgsl()` is appended after the
   module (like `vdbFrameIntegrateWgsl`), so module bytes and the generator snapshot don't move, and a host that
   only wants the hit keeps calling `vdbLevelSetHit`.
2. **three's `wgslFn` takes built-in types only**, so the material's entry packs the struct into a `mat4x4f`;
   one call site per shader (compile time, K3.7). The normal is now computed with every hit, also in shadow and
   depth passes (+6 samples per hit texel there; V90).
3. **The raw pass reads the pool only in the fragment stage**: the proxy corners come from `pool.info` on the CPU,
   so the vertex stage needs no storage buffer (compat devices allow 0 there).
4. **frag_depth discards outside `[0, 1]`** (a hit before the near plane is clipped as a mesh would be).
