WebVDB Examples

OpenVDB/NanoVDB volumes on the web — WebGPU + three.js (TSL). Demos land phase by phase (docs/PLAN.md):

  1. 01 · hello-nvdb — read voxels in a TSL compute pass (VDBGridNode)
  2. 02 · cloud — NanoVDB fragment raymarch, sun-lit (Phase 3)
  3. 03 · gpu-read — annotated educational example (Phase 3)
  4. 04 · atlas-fallback — compute → Data3DTexture (Phase 4)
  5. 05 · embergen-sequence — animated NanoVDB playback (Phase 7)
  6. 06 · explorer — drag-drop VDB inspector (Phase 5/8)
  7. 07 · builder — in-browser grid authoring (Phase 5)
  8. 08 · webgpu-smoke — raw WebGPU, no engine: @pmndrs/vdb core only (K1.7)
  9. 09 · coarse-first — stream a 12 KiB preview grid, then the full grid, with a live byte counter (K4.20)
  10. 10 · frame-renderer — the froxel renderer (K3), interactive: clouds, smoke, an emissive explosion, a level set and points, with live lighting, scattering, phase, spectral, shadow and quality controls
